Chuyển file HTML exocad sang STL

Tách từng lớp trong bản xem trước HTML (thiết kế, mẫu hàm, hàm đối…) thành file STL.

File được xử lý ngay trên máy của bạn, không tải lên máy chủ.

Đang mở bản xem trước

Bản xem trước do exocad dựng. Bạn có thể xoay, bật hoặc tắt lớp ở đây để đối chiếu.
