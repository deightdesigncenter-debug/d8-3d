Who we are

A design team, nothing else

Today D.EIGHT is a dedicated design team. Implant work is our core: single implant crowns, custom abutments, All-on-X bridges and bars. Around it we cover crown and bridge, removable and appliance design.

We only design. No milling, no printing, no shipping, so every hour goes into the file you send to your own mill, printer or production partner.

Upper arch, 17 to 27

02

Screw access off the cusps

Seen from the biting surface, each screw channel comes out away from the cusp tips, so the chewing surfaces stay whole.

Five multi-unit seats

The underside sits directly on five multi-unit abutments, built from the OPTISPLINT direct-to-MUA library so each seat matches its abutment.

04

The same tooth library and the same smile line as the upper arch, with the gingiva shaped in the same wax-up.

05

Both arches together

The bite is checked on the full set in exocad before any file is exported, not one tooth at a time.
